# 💵 USD Currency Converter

A simple and user-friendly **USD Currency Converter** built with **Python and Streamlit**. The application uses the **ExchangeRate-API** to fetch exchange rates and converts USD into the selected country's currency.

## 🚀 Features

- 💵 Convert USD to different currencies
- 🌍 Select a country from a dropdown
- 🔢 Enter any USD amount
- 🔄 Fetch exchange rates using ExchangeRate-API
- ⚡ Fast and interactive Streamlit interface
- 🔐 Secure API key management using environment variables
- 📄 Country and currency information loaded from a JSON file

## 🛠️ Technologies Used

- Python
- Streamlit
- Requests
- python-dotenv
- JSON
- ExchangeRate-API
